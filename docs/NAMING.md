# Quick Aside — Naming Decision v0.2

Status: **Accepted for project/bootstrap use**
Decision date: 2026-09-02

## Accepted name

**Quick Aside**

Working product thesis:

> A thought appears while the user is doing something else; Quick Aside captures and files it with minimal interruption so the user can continue.

The name intentionally describes the interaction metaphor rather than the implementation technology. It must not constrain the product to voice, AI, tasks, notes, or a specific provider.

## Naming rules

- Product/display name: `Quick Aside`.
- Suggested repository slug: `quick-aside`.
- Do not introduce `VoiceApp` in new product UI, docs, code symbols, repository names, or new external-service identifiers.
- Android application/package ID is **not decided here**. Choose it during bootstrap based on a stable reverse-DNS namespace the owner can safely use.
- Final icon, exact colors, typography, and broader brand identity remain separate future design decisions.

## Preliminary availability screen

A preliminary exact-name screen was performed before adoption across general web search, app-store-oriented queries, GitHub-oriented queries, and trademark-oriented web results. No obvious active software/product named exactly `Quick Aside` was found in the reviewed results.

This is sufficient for a private/personal project bootstrap. It is **not legal trademark clearance** and does not guarantee domain, handle, company-name, or trademark registrability. Before public commercial release, paid marketing, or trademark filing, repeat a formal availability/clearance check across the intended jurisdictions and classes.
